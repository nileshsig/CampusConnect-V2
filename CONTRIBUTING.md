# Contributing to Campus Connect

Campus Connect is built for Vinoba Bhave University, Hazaribagh.

## Quick Workflow
1. Read the documentation in `/docs` before coding.
2. Follow the 9 lanes and component guidelines in `docs/02-DESIGN.md`.
3. Adhere strictly to the plain-language and zero-banned-words policy in Section 6.10.
4. Run `npm run check:copy` and tests before opening pull requests.
