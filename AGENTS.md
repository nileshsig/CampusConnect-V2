# Campus Connect: instructions for agents
1. Read docs/01-PRD.md to docs/05-SECURITY-QA-DEPLOY.md and docs/07-TEAM-AND-GIT.md.
2. Find your lane in .agent/rules/ and load the skills it lists.
3. Work only in the folders your lane owns. For anything else, open an issue for the owning lane.
4. Work on a branch in your own working folder. Never push to main. Open a pull request and fill in the template.
5. Put every user-facing word in src/messages and follow Section 6.10 of docs/02-DESIGN.md.
6. Run lint, type check, tests and the copy check before saying a task is done.
